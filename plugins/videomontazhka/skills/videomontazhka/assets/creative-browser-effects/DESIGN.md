# SPRUT Creative Browser Effect Contract

- Palette: `#070707`, `#121212`, `#FF6A00`, `#FFFFFF`, `#A8A8A8` only.
- Typography: the pinned local Unbounded, Golos Text, and JetBrains Mono pack.
- Orange signals a semantic accent; it is not a decorative wash.
- One dominant motion idea per effect. Effects must clarify an approved beat.
- First visible motion begins between 0.1 and 0.3 seconds and uses eased motion.
- Every time-varying property belongs to the registered paused GSAP timeline.
- Random-looking layouts use only the recorded integer seed.
- Network, CDNs, URL-loaded Lottie, telemetry, paid APIs, and Remotion are off.
- Three.js is experimental and defaults off. Shader transitions default blocked.
- Generated instances are source assets, not approved renders. A visual sheet,
  release QA, and full-preview user approval remain mandatory.
