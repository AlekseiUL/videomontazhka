# Синтетический пример без медиа

Эта папка показывает ожидаемый разговор и формат доказательств, не содержит видео, голоса, персональных данных или API-вызовов. `transcript.fixture.json` — явно искусственный word-level fixture для разработки; его нельзя выдавать за результат провайдера или привязывать к реальному source manifest.

## Цель

Из условного длинного объяснения собрать ролик на 60–75 секунд: показать, почему надёжный агент сначала фиксирует стоимость и смысл, а потом рендерит.

## Запрос в Codex

```text
Используй $videomontazhka. Это синтетический учебный проект без реального
медиа. Прочитай brief.md и transcript.fixture.json, покажи смысловой план,
но не создавай production approval и не вызывай сеть. Объясни четыре gate и
собери черновик release pack в Markdown.
```

## Что должно произойти

Агент обязан явно сказать, что media source и его SHA-256 отсутствуют, поэтому production EDL/render/approval невозможны. При этом он может безопасно:

- разобрать искусственные тезисы;
- предложить hook и структуру;
- показать места удаления filler/repeat;
- предложить минимальную творческую карту;
- сформировать DRAFT публикационного пакета.

Ожидаемый пример находится в `expected-release-pack.md`. Он не является SEO-обещанием для реального ролика.

## Чему учит fixture

1. Текстовые данные не заменяют source hash.
2. Пример не должен случайно пройти production approval.
3. Для демонстрации смысла не нужны чужие видео и платная транскрибация.
4. DRAFT всегда маркируется DRAFT до media QA и человеческого preview.
